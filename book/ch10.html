数据快照 2026-09

某大型集团企业的"月度经营分析报告"原来由一位分析师花两天完成。2025 年底，数据团队把它自动化：一个 Agent 挂上财务、销售、供应链三套数据库的查询工具，按固定模板生成初稿。单 Agent 版本跑得通，但每次要把三个域的指标定义、口径说明、历史备注一起塞进上下文，Prompt 长度很快顶到上限，模型开始漏读后一半的口径注释，报告里出现了"营收按含税口径、毛利按不含税口径"这类自相矛盾的数字。

团队决定拆。方案是六个 Agent：财务、销售、库存、履约、供应链各一个业务域 Agent，再加一个汇总 Agent。域 Agent 只负责本域的取数与口径判断，汇总 Agent 负责拼装和交叉校验。第一次跑通，团队以为问题解决了。

上线后的第一个月，三个问题一起浮出来。
